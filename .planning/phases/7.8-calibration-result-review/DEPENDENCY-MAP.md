## 1. Canonical Result Contract

**Canonical:** `domain/calibration_session.py::CalibrationResult` (frozen, eq=False)

| Field                    | Type              | Notes                                                      |
| ------------------------ | ----------------- | ---------------------------------------------------------- |
| calibration_id           | str               | non-empty                                                  |
| sequence_id              | str               | primary orientation                                        |

| projector_id             | str               |                                                            |
| camera_id                | str               |                                                            |

| projector_intrinsics     | NDArray (3,3)     | fx,fy,cx,cy                                                |

## 2. Upstream Producers

```
ProductionWorkflow (application/calibration_workflow.py)
  └─ calibration_result: CalibrationResult | None   (set by solve stage)
  └─ is_synthetic: bool  → source_mode
  └─ hardware_pending: tuple[str,...]  (7 gates)
       1. optical closure
       2. real frameSwapped/vsync
       3. settle time
       4. camera buffer policy
       5. real sentinel coverage
       6. physical two-plane calibration
       7. repeatability
```

Solver (`calibration/solver.py::solve_calibration`) → canonical result.
Reconstruction (`services/reconstruction.py`) → feeds solver.
Decoder (`services/structured_light_decoder.py`) → feeds reconstruction.

Review layer must NOT call any of these.

## 3. Downstream Consumers

```
CalibrationResultReviewViewModel
  └─ ProductionWorkflow.calibration_result
       ↓
CalibrationResultReviewWidget
       ↓ (signals)
Host / Phase 7.9 Warp Preview
  accepted_for_preview → handoff
  rejected / needs_recalibration / cancelled → control
```

Warps: `domain/warp_mesh.py::WarpMesh` already inside result — do NOT regenerate.

OutputManager / Output safety: not bypassed; eligibility ≠ physical certification.

## 5. Validation Semantics (reuse, don't invent)

Canonical validator: `calibration/validator.py::CalibrationValidator`
Defaults: max_error 2.0, min_samples 5, min_confidence 0.5
Infrastructure validator: `infrastructure/projector_calibration/validation.py`

ReviewViewModel mirrors these thresholds for warnings/blocking_errors; no solver math.
