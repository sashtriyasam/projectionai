# Product Positioning Audit

**Date**: 2026-08-31

---

## What is ProjectionAI?

A desktop application that calibrates a projector to a physical surface using camera feedback, then warps and projects content onto that surface — with optional AI-generated content.

## Who is it for?

Projection artists, event designers, stage technicians, and creative technologists who need to map projected content onto physical objects and surfaces.

## What does it let you do?

1. **Calibrate** — Automatically determine projector-to-surface geometry using a camera
2. **Warp** — Transform content to match the physical surface shape
3. **Generate** — Create projection content using AI (optional)
4. **Preview** — See exactly what will be projected before going live
5. **Project** — Send warped content to a projector with safety controls

## Accurate one-line description

> Desktop projection mapping software: calibrate, warp, and project content onto physical surfaces using camera-based calibration and optional AI generation.

## What it is NOT (yet)

- Not production-ready for live shows (physical validation pending)
- Not a cloud service
- Not a mobile app
- Not a replacement for professional mapping software (yet)

## "ChatGPT for Projection Mapping" framing

This is the **long-term vision**, not the current product. The current product is a projection mapping tool with AI content generation capability. The vision is to make projection mapping as simple as describing what you want in natural language.

**Current state**: The calibration pipeline works in software tests. Physical hardware validation (camera + projector + surface) is pending.

---

## Positioning for README opening

**Primary**: Desktop projection mapping software
**Secondary**: AI-powered content generation for projection
**Vision**: Natural-language-driven projection mapping

The README should lead with the concrete, current capability (calibration + warping + projection), not the aspirational vision.
